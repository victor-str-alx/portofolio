# Personal Portfolio — Victor-Alexandru Strîmbeanu

A responsive personal portfolio website presenting my profile, selected projects, technical skills, professional experience, and academic background. The portfolio is focused on my development towards Junior Data Analyst roles, while also showing the software, database, and infrastructure experience that informs my approach to working with data.

## Overview

The website brings together project work and professional background in one place. It highlights practical data analysis and business reporting first, with additional projects that demonstrate experience with relational databases, data visualisation, and software applications.

The featured project is **Superstore Sales & Profitability Analysis**, an end-to-end retail analysis using Microsoft Excel, Google BigQuery (SQL), and Looker Studio. The portfolio also links to an interactive dashboard and the supporting project repository.

## Technology

The portfolio is a lightweight static website built with:

- **HTML5** for page structure and content
- **CSS3** for layout, responsive styling, and visual presentation
- **Vanilla JavaScript** for mobile navigation and project-category filtering
- **GitHub Pages** for static website hosting

No frontend framework, package manager, backend service, or build process is required.

# Victor-Alexandru Strîmbeanu — Portfolio Website

A responsive, static portfolio website for a Junior Data Analyst profile. Built with plain HTML, CSS and JavaScript so it can be hosted directly on GitHub Pages without a build step or external dependencies.

## Contents

- `index.html` — page structure and portfolio content
- `styles.css` — responsive visual design
- `script.js` — mobile navigation and project filters
- `assets/Victor-Strimbeanu-CV.pdf` — downloadable one-page CV
- `assets/favicon.svg` — site icon

## Publish at `https://victor-str-alx.github.io/portfolio/`

1. Create a **public** GitHub repository named `portfolio` under `victor-str-alx`.
2. Upload the *contents* of this folder to the repository root. `index.html` must be at the top level, not inside another folder.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. After GitHub Pages finishes publishing, open `https://victor-str-alx.github.io/portfolio/`.

## Updating the site

Edit the text and links in `index.html`. Adjust layout and colours in `styles.css`. The page does not require npm, a framework, or a build command.

## Before sharing with recruiters

- Confirm the phone number and email are the contact details you want public.
- Confirm that the downloadable PDF is the current CV version.
- Open the live Looker Studio dashboard in a private/incognito window to confirm its viewer permissions.
- Check that every repository and dashboard link is publicly accessible.
